## Using a file with ATSR

1. In ATSR, switch on **Enable Local RPM Folder** (ATSR-Hub EVO > Universal Settings > RPM Settings >
   Developer Settings).
2. Download the car's `.json` file (open it above, then use GitHub's download button) and put it in
   `<SimHub folder>\_ATSR_DevelopmentData\rpm_data\`. Keep the file name as it is: ATSR finds the file
   by that name.
3. Load the car in game. If the lights don't change, press ATSR's **Force RPM Reload** or re-enter the
   car.

ATSR uses a file in that folder instead of the official one for as long as it's there. Delete it once
the car is in Lovely Car Data, so you get any later fixes from the official repo.

The folder doesn't separate games, so two games with a car of the same file name can't both be there
at once. None of the cars above clash, but check before adding files of your own.
